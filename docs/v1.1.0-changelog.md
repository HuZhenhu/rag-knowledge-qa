## Bug 修复

### 1. 登录接口缺少 user 字段
**问题**: 前端 `auth.ts` 执行 `JSON.parse(data.user)` 时 `data.user` 为 `undefined`，导致 `localStorage` 存储 `"undefined"` 字符串，下次登录时 `JSON.parse("undefined")` 报错白屏。

**修复**:
- `src/api/schemas.py`: 新增 `UserInfo` 模型，`TokenResponse` 添加 `user` 字段
- `src/api/routes.py`: 登录接口返回 `{id, username, role}` 用户信息

### 2. 前端 CSS 变量缺失导致白屏
**问题**: `Login.vue` 使用 `--bg-surface`、`--text-3`、`--radius` 等 CSS 变量，但 `style.css` 未定义。

**修复**: 在 `:root` 和 `@media (prefers-color-scheme: dark)` 中添加缺失的变量。

### 3. 主题未初始化导致白屏
**问题**: `data-theme` 属性未设置，CSS 变量全部为 `undefined`。

**修复**: `main.ts` 启动时读取 `localStorage` 并设置 `data-theme`。

### 4. 路由权限过于严格
**问题**: 索引监控、查询日志、评测、用户管理页面设置 `roles: ['admin']`，`viewer` 角色无法访问。

**修复**: 将这些页面的权限改为 `['viewer', 'editor', 'admin']`。

### 5. 前端 API 代理缺失
**问题**: 前端请求 `/api/v1/*` 发送到 5173 端口，后端在 8080 端口，导致 404。

**修复**: `vite.config.ts` 添加 proxy 配置，将 `/api` 和 `/ws` 转发到 `localhost:8080`。

## 依赖兼容性修复

### 问题描述
Python 3.13 环境下，多个包存在版本冲突：
- `torch 2.7.0` 与 `transformers 5.12.0` 不兼容（`AuxRequest` 缺失）
- `transformers 4.44.0` 需要 `tokenizers 0.19.x`，但 Python 3.13 无预编译包
- `tokenizers` 需要 Rust 编译，网络无法下载 Rust 工具链
- `torchvision 0.27.0` 与 `torch 2.7.0` 不兼容（`nms` 算子缺失）

### 最终解决方案
```bash
# 通过 conda 安装预编译包（避免 Rust 编译）
conda install -c conda-forge tokenizers transformers sentence-transformers

# 降级 transformers 到兼容版本
python -m pip install transformers==4.48.0 --only-binary :all: --no-deps

# 降级 huggingface-hub
python -m pip install "huggingface-hub>=0.24.0,<1.0" --only-binary :all: --no-deps

# 卸载不兼容的 torchvision
python -m pip uninstall torchvision -y
```

### 最终版本组合
| 包 | 版本 |
|---|---|
| torch | 2.7.0 |
| transformers | 4.48.0 |
| tokenizers | 0.21.0 |
| huggingface-hub | 0.36.2 |
| sentence-transformers | 2.7.0 |
