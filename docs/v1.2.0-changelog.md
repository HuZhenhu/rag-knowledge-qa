# v1.2.0 版本更新说明 — LangChain框架集成

## 更新日期
2026-06-15

## 版本亮点

### 🚀 LangChain框架集成

本次更新将RAG核心引擎迁移到LangChain框架，对标业界主流选择。

## 新增功能

### 1. LangChain RAG引擎 (`src/core/langchain_rag.py`)

基于LangChain组件重构的RAG引擎，支持：

| 组件 | LangChain组件 | 说明 |
|------|---------------|------|
| LLM调用 | `ChatOpenAI` | 兼容DeepSeek/OpenAI API |
| Embedding | `OpenAIEmbeddings` | 统一Embedding接口 |
| 向量存储 | `Chroma` | langchain-chroma集成 |
| 混合检索 | `EnsembleRetriever` | 向量+BM25融合 |
| 关键词检索 | `BM25Retriever` | langchain-community |
| Prompt模板 | `ChatPromptTemplate` | 结构化Prompt管理 |
| 输出解析 | `StrOutputParser` | LCEL管道组件 |

### 2. LCEL管道构建

使用LangChain Expression Language (LCEL) 构建RAG管道：

```python
self.chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | self.prompt
    | self.llm
    | StrOutputParser()
)
```

### 3. 双引擎切换

通过环境变量 `RAG_ENGINE` 切换引擎：

```bash
# 使用LangChain引擎（默认）
RAG_ENGINE=langchain

# 使用原版引擎
RAG_ENGINE=original
```

## 使用示例

### Python代码

```python
from src.core.langchain_rag import LangChainRAGEngine

# 初始化引擎
engine = LangChainRAGEngine()

# 执行查询
response = engine.query(
    question="什么是RAG？",
    top_k=5,
)

print(response.answer)
print(response.sources)
```

### API调用

```bash
# 登录获取Token
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin01", "password": "123456"}'

# 查询
curl -X POST http://localhost:8080/api/v1/query \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"question": "什么是RAG？", "top_k": 5}'
```
